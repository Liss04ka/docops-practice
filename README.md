# DocOps Demo — документация проекта

Добро пожаловать в репозиторий документации проекта **DocOps Demo**. Здесь хранится пользовательская и техническая документация в формате Markdown, а также конфигурации для сборки и публикации.

## Структура
- `docs/overview.md` — обзор продукта
- `docs/user-guide/installation.md` — установка и обновление
- `docs/user-guide/getting-started.md` — начало работы
- `docs/api/` — спецификация и примеры API
- `docs/architecture/` — архитектура и принципы работы

## Быстрый старт (документация)
1. Откройте раздел «Начало работы»: `docs/user-guide/getting-started.md`.
2. Следуйте шагам установки из `docs/user-guide/installation.md`.
3. Посмотрите примеры API в каталоге `docs/api/`.
